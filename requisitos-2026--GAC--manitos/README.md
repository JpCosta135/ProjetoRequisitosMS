# 📑 GAC - Gestão de Ativos (CCT - Unifor)
## 📋 Sobre o Projeto
O GAC é um projeto de extensão desenvolvido para a disciplina de Requisitos e Modelagem de Sistemas no segundo semestre de ADS na Unifor. O objetivo é substituir o controle manual de empréstimos de equipamentos (projetores e chaves) por uma plataforma digital integrada a identificadores físicos como NFC e QR Code.  

## 🚀 Milestone M1: Elicitação e Modelagem Inicial
Este repositório contém a documentação da primeira fase do projeto, focada em entender o problema real e desenhar a arquitetura inicial da solução.

### 🔍 Elicitação de Requisitos
A fase de descoberta baseou-se em:

Análise Documental: Estudo dos formulários físicos de Termo de Responsabilidade e planilhas legadas.
Entrevista com Stakeholder: Entrevista técnica com o auxiliar administrativo Kildery para entender o fluxo de 36 projetores e chaves.  
Identificação de Dores: Lentidão no atendimento, falta de rastreabilidade em tempo real e falhas no checklist de acessórios (cabos HDMI).

### 🛠️ Artefatos de Modelagem (UML)
Documento de Visão: Definição clara do problema e público-alvo.
Diagrama de Casos de Uso: Representação das interações entre Professores e Atendentes.
Diagrama de Classes: Estrutura de dados para Ativos, Empréstimos e Termos Digitais.
Diagrama de Sequência: Fluxo lógico desde a leitura do QR Code até a liberação do ativo.

## 📋 Backlog Priorizado
O desenvolvimento foi planejado em sprints para garantir um MVP (Minimum Viable Product) funcional:
Sprint 01: Inventário de ativos e identificação de stakeholders.
Sprint 02: Fluxo de empréstimo mobile e formalização digital.
Sprint 03: Checklist de devolução e painel gerencial de rastreamento.

## 🛠️ Tecnologias e Ferramentas
Modelagem: Lucidchart / Draw.io.
Prototipagem: Figma.
Documentação: Padrão IEEE 830.
